## 2. End-to-End Request Trace (`POST /capabilities/image/generate`)

*(Note: Items marked **[INFERRED FROM READING]** are traced directly from source code on commit `af47a91` and will be marked **[VERIFIED BY LIVE RUN]** upon executing Step 3).*

1. **JSON Request Arrival:** Client sends an HTTP `POST` request with JSON body (`prompt`, `negative_prompt`, `width`, `height`, `steps`, `guidance_scale`, `seed`, `observation`) to `/capabilities/image/generate` in `backend/api.py` **[INFERRED FROM READING]**.
2. **Pydantic Validation (`contract.py`):** FastAPI parses the JSON body into `ImageGenerationRequest`. Pydantic validates field constraints (`min_length=3`, `multiple_of=64`, numeric bounds). If validation fails, `validation_exception_handler` in `backend/api.py` intercepts `RequestValidationError` and returns HTTP `422` with `"status": "validation_error"` without invoking the model **[INFERRED FROM READING]**.
3. **API Route Dispatch (`backend/api.py`):** On valid input, synchronous route `generate_image(request)` calls `capability_runner.execute(request)` on the module-level `ImageGenerationCapability` singleton **[INFERRED FROM READING]**.
4. **Model Load & Inference (`service.py`):**
   * `execute()` generates an 8-char UUID (`run_id`), UTC ISO `timestamp`, and starts `time.perf_counter()` **[INFERRED FROM READING]**.
   * If `self.pipe is None`, `load_model()` loads `CyberRealistic_V9_FP16.safetensors` via `StableDiffusionPipeline.from_single_file(..., torch_dtype=torch.float32, use_safetensors=True)`, replaces the scheduler with `EulerDiscreteScheduler.from_config(self.pipe.scheduler.config)`, moves the pipeline to `cpu`, and enables `enable_attention_slicing()` **[INFERRED FROM READING]**.
   * Creates a deterministic CPU generator (`torch.Generator(device="cpu").manual_seed(request.seed)`) and runs `self.pipe(...)` **[INFERRED FROM READING]**.
5. **PNG Output Path (`service.py`):** Creates `outputs/` directory if absent, extracts `result.images[0]`, formats path `outputs/{MODEL_NAME}_seed{seed}_{run_id}.png` (normalising backslashes to `/`), and writes the PNG to disk via PIL `image.save(output_path)` **[INFERRED FROM READING]**.
6. **Response Model Construction (`service.py` -> `contract.py`):** Instantiates `ImageGenerationResponse(status="success", ...)` (or `status="error"` with `[ERROR_CATEGORY]` if an exception was caught) **[INFERRED FROM READING]**.
7. **Experiment Log Persistence (`contract.py`):** Calls `log_experiment_run(response.model_dump())`, which reads `experiments/experiment_log.json`, appends the new dictionary, and writes the updated JSON array to disk before `backend/api.py` returns the HTTP `200` (or `500`) JSON response **[INFERRED FROM READING]**.
